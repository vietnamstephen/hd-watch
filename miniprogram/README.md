# HD 户外周报 —— 微信小程序

把 `hd-watch` 看板的核心内容做成微信小程序，每周更新一次。

## 三个页面

| 页面 | 内容 |
|---|---|
| 概览 | HD 股价与近 120 日走势（canvas 手绘）、价格位置、估值与经营指标、相对 Lowe's/标普/零售指数表现、本周新闻、SEC 表单、IR 材料 |
| 明星产品 | Patio 三层分组 buzz 榜（家具/设备/配件）、跨品类综合明星榜、新星榜、品类构成、评分方法与口径限制 |
| 渠道对标 | Amazon / HD / Lowe's 特征对比、两家的公开单品、来源与可靠性、数据边界说明 |


## 每周更新流程（已挂自动化，周日 09:00）

```bash
cd hd-watch/scripts
python run_cycle.py            # 1. 刷新原始数据
python build_miniprogram.py    # 2. 重新生成 mini.js（38 KB 左右）
python check_miniprogram.py    # 3. 自检，必须全部通过
python make_tabbar_icons.py    #    （图标不会变，一般不用重跑）
```

之后需要人点一下：**打开应用「HD 户外周报」的预览面板 → 右上角「分享」→ 上传新版本**。
小程序没有链接可自动更新，这是微信生态的固定环节。

## 两个关键设计决定

1. **数据内置，不走接口。** 微信要求 `wx.request` 的域名在小程序后台配置为合法域名
   且完成 ICP 备案与归属校验；WorkBuddy 发布的看板域名不满足，走不通。
   数据随包发布（约 38 KB，主包上限 2 MB），换来的是零后端、离线可看、无鉴权问题。
2. **图表全部用 WXML/WXSS 与原生 canvas 实现，不引入 ECharts 小程序版。**
   榜单条形图用 `view` + 百分比宽度，走势图用 canvas 2d 手绘 —— 包体小、无第三方依赖、深浅色通过主题变量直接适配。

## 已知边界

- HD / Lowe's 站内数据因指纹级反爬拿不到（详见看板第 12 章），小程序里同样只呈现
  公开披露信息并逐条标注来源等级。
- 小程序不能直接打开外部链接，新闻/表单/商品点击均为「复制链接」。
- 正式版发布需要微信审核（通常 1-3 天）；审核通过前可先用体验版扫码看效果。
